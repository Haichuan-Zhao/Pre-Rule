# Pre-Rule：项目规范

**当前版本：0.1.1**

Pre-Rule 是一项项目探索规范。Codex 根据当前任务和已有目录，安排代码、数据、结果与图片的位置，有逻辑地开展实验和绘图，并解释主要产物。使用时无需额外准备输入文件或固定模板。

## 使用

在项目中调用 `$pre-rule`，例如：

```text
使用 $pre-rule，完成当前任务，按实际工作阶段组织文件，并说明实验结果与主要产物。
```

技能允许自动选择，但不能保证每次请求都会自动触发；需要明确使用时直接写 `$pre-rule`。用户本次指定的文件结构和其他具体要求优先。

首次安装时，在本地仓库根目录将技能复制到 Codex 的技能目录：

```bash
mkdir -p ~/.codex/skills
cp -R .agents/skills/pre-rule ~/.codex/skills/
```

如果使用 Skills Manager 管理技能，也可以在本仓库目录向 Codex 发送：

```text
使用 $manage-skills，将本项目 .agents/skills/pre-rule 作为本地来源安装并部署到 Codex。
```

已通过 Skills Manager 安装的技能，在修改源文件后用同一管理器更新并检查 Codex 部署状态。

## 目录示例

原始和预处理数据集中存放，实验 notebook 直接读取；代码、结果和图片按实验阶段组织。每个项目内容目录都有简短的 `readme.md`。以下只是示例，文件和目录按实际需要创建。

```text
proj/                            # 项目名称按具体用途取简称
├── readme.md
├── data/
│   ├── readme.md
│   ├── raw/                     # 原始数据
│   │   ├── readme.md
│   │   └── obs.csv
│   ├── pre/                     # 处理后数据
│   │   ├── readme.md
│   │   └── obs.csv
│   └── pre.ipynb
└── exp/
    ├── readme.md
    └── 01_feat/
        ├── readme.md
        ├── feat.ipynb
        ├── res/                 # 本阶段实验结果
        │   ├── readme.md
        │   └── met.csv
        └── fig/
            ├── readme.md
            └── feat.jpg
```

## 主要规则

- 按任务创建文件，不预建空目录、占位文件、演示数据或多余的计划、日志和报告。
- 项目、目录和文件使用简洁、易理解的名称，优先采用英文单词或常用缩写；自编代码文件名不得用 `run` 表示运行入口，不区分大小写。
- 原始数据和预处理数据分别放在 `data/raw/` 和 `data/pre/`，实验代码直接读取，不在 `exp/` 下复制；原始数据保持原样。
- 指标表、预测表、模型等实验结果放在所属实验阶段的 `res/`，图片放在该阶段的 `fig/`。后续实验需要已有结果时直接引用原路径，不重复复制。
- 每个项目自有内容目录都维护一份简洁的 `readme.md`，说明当前文件、子目录和必要的输入输出关系；已有 `README.md` 可直接沿用。`.git`、依赖、缓存和第三方目录不写入。
- 同一用途的 notebook、处理后数据、结果和图片默认在原路径迭代覆盖，并按需更新相关产物；不为日常修改创建备份、版本副本或压缩包。用户要求或实验对照确需并存时，按用途分别保存。
- 所有自编科研和分析逻辑直接写在相应阶段的 notebook 代码单元中，不能用自编脚本或命令行计算后再补 notebook。第三方库可正常使用，非科研分析的工程代码按项目需要组织。
- 代码按实际步骤直接实现，避免难以理解的抽象逻辑和无必要的封装；变量使用简洁、易懂的英文单词或常用简称，如 `feat`、`pred`、`err`。
- notebook 单元只展示需要的结果，例如数据预览、关键指标和图表，避免长表格、数组、无意义对象文本和重复日志；保留错误与影响结果的重要警告。
- 实验围绕研究问题和实际数据推进，在 notebook 中说明方法、结果和必要局限；按需绘制与结果对应、可追溯的图片。
- 完成时说明主要文件的作用、数据流向、图表含义和未执行的步骤。

完整规则和目录示例见 [SKILL.md](.agents/skills/pre-rule/SKILL.md)。

## 绘图偏好

- 以直观易懂为首要目标，优先使用折线图、散点图、柱状图等常见二维图表；图中说清比较对象、工况、变量和单位。
- 优先白底、清晰坐标轴和少量配色；对比曲线同时使用不同颜色、线型或标记，多个子图按工况或变量有规律地排列。
- 图表默认中文标注、高质量 JPG；投稿要求或用户指定的格式、语言优先。图表数据可追溯到原始或结果文件，绘图代码保存在所属 notebook 中。

视觉参考包括 [Tao 等（2024）](https://www.nature.com/articles/s41467-024-54454-0)和 [Che 等（2026）](https://www.nature.com/articles/s41467-025-67565-z)论文中的分组和对比图，以及用户提供的多工况曲线示例。规则优先采用其中清楚、易读的做法。
